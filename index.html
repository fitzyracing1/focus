focus

Minimal, uniform C++ AI Model interface (header-only)

One abstract ai::Model that works the same for local models, remote APIs, or any backend you plug in later.

Zero dependencies. Drop the header in and go.

Download ai-iface.hpp

Usage

#include "ai-iface.hpp"
#include <iostream>

int main() {
    auto brain = ai::create();               // mock by default
    std::cout << brain->infer("hello") << std::endl;
}
